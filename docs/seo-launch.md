# Dudo SEO Launch & Search Console Checklist

This document provides a step-by-step checklist to verify, validate, and launch Dudo's enterprise-grade SEO configuration on Google Search Console, Bing Webmaster, and other search crawlers.

---

## 📋 1. Search Console Setup & Verification

Google Search Console is the primary tool to track indexing, performance, search keywords, and rich snippets.

### Step 1: Add a New Property
1. Visit [Google Search Console](https://search.google.com/search-console/).
2. Click the property dropdown in the top-left corner and select **"Add property"**.
3. Choose **"Domain"** verification method (recommended) and enter `dudo.site`.

### Step 2: DNS TXT Verification
1. Copy the TXT record value generated by Google.
2. Go to your domain registrar DNS settings (e.g. GoDaddy, Namecheap, Cloudflare).
3. Add a new **TXT** record:
   - **Host/Name**: `@` or blank
   - **Value**: `google-site-verification=...` (your copied string)
   - **TTL**: `1 Hour` (or default)
4. Click **"Verify"** in Search Console. *Note: DNS changes can take up to 30 minutes to propagate.*

---

## 🗺️ 2. Sitemap & Robots Submission

Now that the site URLs are pointing to the correct production domain (`https://dudo.site`), submit them to Google for automatic indexing.

### Step 1: Submit sitemap.xml
1. In Search Console left sidebar, click **"Sitemaps"** under the "Indexing" section.
2. Under "Add a new sitemap", type: `sitemap.xml`.
3. Click **"Submit"**.
4. Confirm status changes to **"Success"** (may take a few minutes to process first time).

### Step 2: Validate robots.txt
1. Test your robots.txt at `https://dudo.site/robots.txt`.
2. Confirm it allows indexing of all static and dynamic paths while explicitly disallowing sensitive paths:
   - `/api/` (noindex)
   - `/dashboard/` (noindex)
3. Confirm the sitemap reference points to: `https://dudo.site/sitemap.xml`.

---

## ⚡ 3. Request Live Indexing

Whenever you update pages or create new posts, request Google to inspect and re-index the URL immediately.

1. In Search Console, click **"URL Inspection"** (or use the top search bar).
2. Enter the URL you want to inspect (e.g. `https://dudo.site` or `https://dudo.site/contact`).
3. Click **"Request Indexing"** to put the URL in Google's priority crawl queue.

---

## 🔍 4. Rich Results & Schema Validation

Validate Dudo's custom JSON-LD schemas (Organization, SoftwareApplication, FAQPage, BreadcrumbList, TechArticle) to make sure they are valid.

### Step 1: Run Rich Results Test
1. Visit the [Google Rich Results Test](https://search.google.com/test/rich-results).
2. Input the URL of your home page: `https://dudo.site`.
3. Verify that the following schemas are detected with **zero errors**:
   - **FAQ** (for homepage search answers)
   - **Product**
   - **Sitelinks Search Box** (triggered by the WebSite search potentialAction)

### Step 2: Structured Data Testing
1. Visit the [Schema Markup Validator](https://validator.schema.org/).
2. Run tests on:
   - Home: `https://dudo.site`
   - Blog posts: `https://dudo.site/resources/blog/<slug>`
   - Guides: `https://dudo.site/resources/guides/<slug>`
3. Ensure no warning or error issues are flagged for structured properties.

---

## 🚀 5. Core Web Vitals & Performance Check

Optimize page speed to boost ranking signals.

### Step 1: Test with PageSpeed Insights
1. Visit [PageSpeed Insights](https://pagespeed.web.dev/).
2. Run analysis on `https://dudo.site`.
3. Check the scores for:
   - **Performance** (Aim for 90+)
   - **Accessibility** (Aim for 95+)
   - **Best Practices** (Aim for 100)
   - **SEO** (Aim for 100)

### Step 2: Optimize Assets
- Ensure all images in `public/` and `app/` are optimized (modern formats like WebP or SVG, proper scaling).
- Preconnect tags for Google Fonts (`fonts.googleapis.com` and `fonts.gstatic.com`) are configured in root layout.
- Manifest file `manifest.ts` is live at `/manifest.webmanifest` to declare web app compatibility.
